# CF 2246C - Alternating Sums 题目讲解

## 一、题目回顾

给定一个**非递减**数组 a，元素为正整数或 -1。

定义「交替和」= b1 - b2 + b3 - b4 + ... + (-1)^(m+1) * bm

问：有多少个子序列（保持原顺序），其交替和等于 0？答案 mod 1e9+7。

---

## 二、核心观察：只有偶数长度子序列可能交替和为 0

### 奇数长度的情况

假设子序列长度为奇数 m = 2k+1，交替和为：
```
b1 - b2 + b3 - b4 + ... + bk - b(k+1) + b(2k+1)
```

重新分组：
```
b1 + (b3 - b2) + (b5 - b4) + ... + (b(2k+1) - b(2k))
```

因为数组是非递减的，b3 ≥ b2, b5 ≥ b4, ...，所以每一对 (b3-b2) ≥ 0。

而 b1 > 0（第一个元素是正整数），整个和 > 0。

**结论：奇数长度子序列的交替和不可能为 0。**

### 偶数长度的情况

m = 2k，交替和为：
```
(b1 - b2) + (b3 - b4) + ... + (b(2k-1) - b(2k))
```

因为数组非递减，b1 ≤ b2, b3 ≤ b4, ...，所以每一项 (b_i - b_(i+1)) ≤ 0。

整个和为 0，**当且仅当每一项都等于 0**。

**即 b1 = b2, b3 = b4, ..., b(2k-1) = b(2k)**。

---

## 三、纯正整数的情况

### 结论

如果数组中每个数都是正整数（无 -1），交替和为 0 意味着：

> 子序列中，每组相等数字必须出现偶数次

### 为什么？

因为 b1 = b2, b3 = b4, ...，相邻两个元素相等，按相等数字分组：

```
[1,1,1,1,2,2,3,3,3,3,4,4]
选出的子序列中：
- 1 的个数必须是偶数（每两个 1 配对成 (1-1)=0）
- 2 的个数必须是偶数
- 3 的个数必须是偶数
- 4 的个数必须是偶数
```

### 有多少种选法？

设值 v 在数组中出现 cnt[v] 次。

从 cnt[v] 个元素中选偶数个的方法数：
```
C(cnt[v], 0) + C(cnt[v], 2) + C(cnt[v], 4) + ...
```

**关键性质：** 选偶数个的方法数 = 选奇数个的方法数 = 2^(cnt[v]-1)

> 证明：对于任意 n 个元素的集合，偶数子集和奇数子集各占一半。

所以值 v 的选法 = 2^(cnt[v] - 1)

所有值的选法相乘：
```
∏ 2^(cnt[v] - 1) = 2^(∑ cnt[v] - 1) = 2^(n - d)
```

其中 d 是不同值的个数。

### 答案

**纯正整数情况：答案 = 2^(n-d)**

---

## 四、含 -1 的情况

现在数组中可能包含 -1。-1 在非递减数组中一定出现在最前面（因为 -1 < 任何正整数）。

### 情况1：选了偶数个 -1

-1 自身配对消除：(-1) - (-1) = 0

此时等价于纯正整数情况：
> 选法数 = 2^(n - d)

（d 是不同正整数的个数，-1 算在内）

### 情况2：选了奇数个 -1

奇数个 -1 的选法：从 c 个 -1 中选奇数个 = 2^(c-1)

现在需要**正整数部分**的交替和等于 +1（来自奇数个 -1 交替和的贡献）。

什么时候正整数的交替和能等于 +1？

回顾偶数长度的分组：
```
(b1 - b2) + (b3 - b4) + ... + (b(2k-1) - b(2k))
```

由于 b1 ≤ b2，每一项 ≤ 0。要达到 +1，需要其中**恰好一项**等于 -1。

即需要一对相邻的值 (v, v+1) 满足：v 出现奇数次，v+1 出现奇数次，且 v+1 - v = 1，使得 (v - (v+1)) = -1。

**条件：** 数组中必须同时存在 v 和 v+1 这两个值。

设 l = 数组中同时存在 v 和 v+1 的 v 的个数（即"相邻对"的个数）。

对于每个这样的对 (v, v+1)，其他值出现偶数次，v 和 v+1 各自出现奇数次。在其它元素出现偶数次的前提下，v 和 v+1 的奇数次选法和偶数次选法一样多（因为选奇数/偶数方法数各占一半）。

所以每种符合条件的 v 贡献的选法数 = 2^(n - d)
不同 v 的贡献加起来 = l * 2^(n - d)

### 合并两个情况

```
情况1（偶数个 -1）: 2^(n-d)
情况2（奇数个 -1）: l * 2^(n-d)

答案 = 2^(n-d) + l * 2^(n-d) = 2^(n-d) * (l + 1)
```

---

## 五、完整公式

```
设 n = 数组长度
设 d = 不同正整数的个数
设 c = -1 的个数

如果 c == 0:
    答案 = 2^(n - d)
    （n - d 就是每家组内挑偶数个）

如果 c > 0:
    设 l = 同时出现 v 和 v+1 的 v 的个数
    总数 = 2^(n - d) * (l + 1)
```

## 六、实现要点

```cpp
// 预处理 2 的幂
pow2[0] = 1;
for (int i = 1; i <= n; i++)
    pow2[i] = (pow2[i-1] * 2) % MOD;

// 统计
int c = 0;  // -1 的个数
set<int> values;  // 正整数值集合
for (int x : a) {
    if (x == -1) c++;
    else values.insert(x);
}

int d = values.size();  // 不同正整数的个数
int l = 0;  // 连续对个数
for (int v : values) {
    if (values.count(v + 1)) l++;
}

int ans = pow2[n - d];
if (c > 0) {
    ans = 1LL * ans * (l + 1) % MOD;
}
cout << ans << endl;
```

## 七、总结

| 步骤 | 关键结论 |
|------|---------|
| ① | 只有偶数长度子序列可能为 0 |
| ② | 偶数长度：相邻元素必须配对相等 |
| ③ | 每组相等值中选偶数个，方法数 = 2^(size-1) |
| ④ | 纯正整数答案 = 2^(n-d) |
| ⑤ | 有 -1 时，奇数个 -1 需要正整数部分交替和为 +1 |
| ⑥ | 交替和为 +1 需要存在相邻对 (v, v+1) 且各选奇数次 |
| ⑦ | 最终答案 = 2^(n-d) × (l+1)，其中 l 是相邻对个数 |
