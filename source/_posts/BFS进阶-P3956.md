> 🎯 **一句话题意**：m×m 棋盘上从左上走到右下，染色耗 1 金币、临时染色耗 2 且不可连续，求最小花费。

[P3956 [NOIP 2017 普及组] 棋盘 - 洛谷](https://www.luogu.com.cn/problem/P3956)
题目大意：
给顶一个$m*m$的棋盘棋盘上可以染两种颜色或者无色，初始时你在$(1,1)$你需要走到右下角，你可以上下左右进行移动，你当前所站的格子必须是有色的(保证起点有颜色)，移动到其他节点时，如果颜色不同则需要一个金币。其他的你可以使用两个金币，将下一个无色各自暂时变成你指定的魔法，注意该魔法不能连续使用，当你离开这个使用魔法的格子该格子颜色立刻恢复无色，求左上角到右下角的最小花费。
思路：
对于正常的点，我们使用简单的上下左右即可移动，但是对于使用魔法后能到的点，我们发现为以下情况的蓝色点，我们直接枚举蓝色点即可，但如果绿色块不为无色块那不就错了吗？我们考虑以下三种情况：
1.绿色块为无色且蓝色和now颜色不同 此时花费为2+1=3
2.绿色块为无色且蓝色和now颜色相同 此时花费为2
3.绿色块不为无色，此时最大的花费为2
如果我们算错当且仅当我把不为无色块的绿色当成无色块，且使得蓝色的贡献严格小于情况3，我们发现这种情况刚好被完美的跳过了，因为情况1,2的花费较高，所以不需要特殊处理这部分。
![](/images/vault/Pasted-image-20260322203402.png)
此时我们只需要保证蓝色绿色的方块有颜色即可，所以状态有12种，但此时如果终点也没有颜色就会错误，此时需要特殊处理一下即如果终点没有颜色，由于不能连续使用，所以终点必须由上面的点或者左边的点转移过来，于是我们取其中较小值即可。
```cpp
const int N = 105;
int g[N][N],cost[N][N];
int dx[]={0,0,1,-1,2,-2,-1,1,0,0,1,-1};
int dy[]={1,-1,0,0,0,0,1,-1,2,2,1,-1};
int dw[]={0,0,0,0,2,2,2,2,2,2,2,2};
struct Node{
	int x,y,c,w;
	bool operator<(const Node&W)const{
		return w>W.w;
	}
	
};
void solve()
{
	int m,n;
	cin>>m>>n;
	memset(cost,0x3f,sizeof cost);
	for(int i=1;i<=n;i++)
	{
		int x,y,c;
		cin>>x>>y>>c;
		g[x][y] = c+1;
	}
	priority_queue<Node>q;
	cost[1][1] = 0;
	q.push({1,1,g[1][1],0});
	while(q.size())
	{
		auto t = q.top();
		q.pop();
		if(cost[t.x][t.y]<t.w) continue;
		//cout<<t.x<<" "<<t.y<<" "<<t.w<<endl;
		for(int i=0;i<12;i++)
		{
			int nx = t.x+dx[i],
			ny=t.y+dy[i],
			nw=dw[i],
			nc = g[nx][ny];
			if(nx<1||ny<1||nx>m||ny>m||!nc) continue;
			if(nc!=t.c) nw++;
			if(cost[nx][ny]>cost[t.x][t.y]+nw)
			{
				cost[nx][ny]=cost[t.x][t.y]+nw;
				q.push({nx,ny,nc,cost[nx][ny]});
			}
			
		}
	}
	//debug(cost[1][1]) 
	int inf = 0x3f3f3f3f;
	if(!g[m][m]){//处理(m,m)无色情况 
		int ans=min(cost[m][m-1],cost[m-1][m])+2;
		if(ans>=inf) cout<<-1<<endl;
		else cout<<ans<<endl;
		return;
	}
	if(cost[m][m]==0x3f3f3f3f)
		cout<<-1<<endl;
	else cout<<cost[m][m]<<endl;
}
```
