> 🎯 **一句话题意**：给定含 o、x、?（? 等概率）的字符串，连击长度平方计分，求最终得分期望。

> 🔗 **原题链接**：[P1365 WJMZBMR打osu! / Easy - 洛谷](https://www.luogu.com.cn/problem/P1365)

由题目可知连续 o 的得分为 $x^2$ (x为长度)
如果再打中一次 则变成了 $(x+1)^2=x^2+2x+1$ 
可以发现增量 $\Delta=(x+1)^2-x^2=2x-1$ 
如果我们在第 $i$ 步之前（也就是第 $i-1$ 步）的连击长度是 $L_{i-1}$，并且我们在第 $i$ 步成功打出了 `o`，那么我们的总分增加了 $2L_{i-1} + 1$

我们设下面三个随机变量
$L_i$：第 $i$ 次点击结束时的 combo（连击）长度。
$F_i$：第 $i$ 次点击结束时的总得分。
$\Delta_i$：第 $i$ 次点击带来的分数增量，即 $\Delta_i = F_i - F_{i-1}$。
下面是对于题目的变化
如果是 `x` (Miss)：连击断了。所以增量 $\Delta_i = 0$。
如果是 `o` (Hit)：   连击接上了。增量 $\Delta_i = 2L_{i-1} + 1$。
如果是 `?` (未知)： 一半概率是 `x`，一半概率是 `o`。

因为题目中有 `?` 的存在，$L_i$ 和 $F_i$ 都不再是确定的值，所以我们要求它们的**期望值**，分别记为 $E(L_i)$ 和 $E(F_i)$。
由期望的线性性质（非常重要的一条性质：$E(A+B) = E(A) + E(B)$），我们可以得出：

$$E(F_i) = E(F_{i-1} + \Delta_i) = E(F_{i-1}) + E(\Delta_i)$$$$E(\Delta_i)=E(2L_{i-1}+1)=2E(L_{i-1})+1$$
也就是说，**当前的期望总分 = 上一步的期望总分 + 这一步带来的期望增量**。所以我们现在的核心任务就是求出 $E(L_i)$ 和 $E(\Delta_i)$,并且我们可以把含 $E(\Delta_i)$ 替换为 $E(L_i)$ ，所以只用维护两个变量即可

此时我们可以把上面的变化引入公式了：
如果是 `x` (Miss)：
$$E(L_i)=0,E(\Delta_i)=0 \Rightarrow E(F_i)=E(F_{i-1})=0$$

如果是 `o` (Hit)：
$$E(L_i)=E(L_i)+1,E(\Delta_i)=E(2L_{i-1}+1)=2E(L_{i-1})+1$$
$E(F_i) = E(F_{i-1}) + 2E(L_{i-1}) + 1$
如果是`?` (未知)：
这相当于应用“全期望公式”（或者说加权平均）。一半概率发生情况 A，一半概率发生情况 B，我们这里先计算 
$E(L_i)$ :
$$E(L_i) = \frac{1}{2}(0) + \frac{1}{2}(E(L_{i-1}) + 1) = \frac{1}{2}E(L_{i-1}) + \frac{1}{2}$$
$E(\Delta_i)$：
$$E(\Delta_i) = \frac{1}{2}(0) + \frac{1}{2}(2E(L_{i-1}) + 1) = E(L_{i-1}) + \frac{1}{2}$$
$E(F_i) = E(F_{i-1}) + E(L_{i-1}) + \frac{1}{2}$ 
自此三个转移式全部推完 按顺序进行遍历DP即可
