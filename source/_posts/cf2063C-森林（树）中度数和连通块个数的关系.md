> 🎯 **一句话题意**：树上删两个点使剩余连通块最多，由度数与相邻关系公式求解。

## 📌 题目大意

给定一棵拥有 $n$ 个节点的树。你需要**恰好执行两次**删除操作：选择一个点 $v$，删掉该点以及所有与它相连的边。求执行两次操作后，图中所能剩下的**最大连通块（Connected Components）数量**。

## 🎯 核心数学基石：连通块公式的推导

在图论中，任何无环图（森林）都满足一个铁律：

$$\text{连通块数量 } C = \text{顶点数 } V - \text{边数 } E$$

当我们在树中选择删除 $u$ 和 $v$ 两个点时：

1. **剩余顶点数**：$V' = n - 2$
    
2. **被删去的边数**：$u$ 带有 $\text{deg}(u)$ 条边，$v$ 带有 $\text{deg}(v)$ 条边。如果 $u$ 和 $v$ 相邻，它们之间连着的那条边就被重复计算了一次。
    
    $$\text{被删边数} = \text{deg}(u) + \text{deg}(v) - [u, v \text{ 相邻}]$$
    
3. **剩余边数**：$E' = (n - 1) - \big(\text{deg}(u) + \text{deg}(v) - [u, v \text{ 相邻}]\big)$
    

将 $V'$ 和 $E'$ 代入公式 $C = V' - E'$ 化简，所有的 $n$ 会被神奇地消去，得到最终的**连通块计算公式**：

$$C = \text{deg}(u) + \text{deg}(v) - 1 - [u, v \text{ 相邻}]$$

> 💡 **人话版本**：
> 
> - 如果 $u$ 和 $v$ **不相邻**：$C = \text{deg}(u) + \text{deg}(v) - 1$
>     
> - 如果 $u$ 和 $v$ **相邻**：$C = \text{deg}(u) + \text{deg}(v) - 2$
>     

通过这个公式，原本复杂的“图论模拟”瞬间变成了 **$O(1)$ 的代数运算**！

## ❌ 常见思维陷阱：为什么连续删“当前最大度数点”是错的？

很多同学（包括你最初的思路）会走入**盲目贪心**的误区：先 DFS 找到全图度数最大的点删掉，在剩下的图里再 DFS 找一个度数最大的点删掉。

**反例说明**：

假设一棵树中，节点 $A$ 度数为 4。节点 $B$ 和 $C$ 度数均为 3，且 $B$ 和 $C$ 不相邻。

- **错误贪心法**：第一步删去 $A$（收益 4），删完后 $B, C$ 的度数都退化成了 2，第二步只能选一个度数为 2 的点。最终答案大约为 $4 + 2 - 1 = 5$。
    
- **全局最优解**：直接选择不相邻的 $B$ 和 $C$。根据公式，它们带来的收益是 $3 + 3 - 1 = 6$。
    

**结论**：不能分步贪心，必须全局考虑两个点的**组合搭配**。

## 🛠️ 三种解法深度对比（因地制宜）

### 解法一：度数排序 + 强力剪枝 (最符合赛时直觉，推荐 ⭐️⭐️⭐️⭐️⭐️)

- **策略**：把所有点按初始度数从大到小排序。使用双重循环枚举点对 $(u, v)$。
    
- **剪枝核心**：如果当前的理论最大可能收益 `deg[u] + deg[v] - 1` 已经小于或等于目前记录的 `max_ans`，由于后面的点度数只会更小，直接 `break` 结束内层或外层循环。
    
- **复杂度**：实际运行近乎 $O(n \log n)$，在绝大多数数据下都是瞬间完成。
    

### 解法二：枚举第一个点 + Multiset 维护度数 (标准时空复杂度 ⭐️⭐️⭐️⭐️)

- **策略**：外层循环遍历第一个被删的点 $u$，同时将其所有邻居的度数在 `std::multiset` 中临时减 1。此时从 `multiset` 中直接取出的最大值就是最优的第二个点。
    
- **复杂度**：严格的 $O(n \log n)$。
    
- **缺点**：`multiset` 内部红黑树常数较大，代码写起来频繁地 `insert` 和 `erase` 较为繁琐。
    

### 解法三：只尝试全局最大度数的前两个点 (Top-2 Greedy ⭐️⭐️⭐️⭐️⭐️)

- **策略**：题解最绝妙的思维。将点按度数从大到小排序后，**第一个点 $u$ 只需尝试排序后的前两个点**，第二个点 $v$ 依然遍历全图。
    
- **科学依据**：树中绝对不可能存在三角形（3-cycle）。如果全图最大的前两个点是 $u_1, u_2$，无论是它们互相组合，还是它们与别的最优解 $w$ 组合，这三者中必定有一对是不相邻的。因此，第一个点锁定前两名，必然能开辟出全局最优解。
    
- **复杂度**：搭配 DFS 预处理父亲节点实现 $O(1)$ 判相邻，全流程可以达到极致的 $O(n)$。
    

## 💻 完美 AC 代码（解法一：排序+剪枝版）

C++

```
#include<bits/stdc++.h>
#define rep(i,n) for(int i=0;i<n;i++)
#define rep1(i,n) for(int i=1;i<=n;i++)
#define IOS ios::sync_with_stdio(false),cin.tie(nullptr);
using namespace std;

const int N = 2e5+10;
vector<int> e[N];
int deg[N];

void solve()
{
    int n;
    cin >> n;
    
    rep1(i, n) {
        e[i].clear();
        deg[i] = 0;
    }

    rep(i, n - 1) {
        int u, v;
        cin >> u >> v;
        e[u].push_back(v);
        e[v].push_back(u);
        deg[u]++;
        deg[v]++;
    }

    // 邻接表排序，方便后面用二进制检索 O(log(deg)) 快速判断两点是否相邻
    rep1(i, n) {
        sort(e[i].begin(), e[i].end());
    }

    // 建立 ID 数组，按照度数从大到小对节点编号进行排序
    vector<int> id(n);
    iota(id.begin(), id.end(), 1); 
    sort(id.begin(), id.end(), [](int a, int b) {
        return deg[a] > deg[b];
    });

    int max_ans = 0;

    for (int i = 0; i < n; i++) {
        int u = id[i];
        for (int j = i + 1; j < n; j++) {
            int v = id[j];
            
            // 核心剪枝：若当前两点即使不相邻的极限收益都无法超越 max_ans，后面更小的 v 也不用看了
            if (deg[u] + deg[v] - 1 <= max_ans) {
                break; 
            }

            // binary_search 快速检测 u 和 v 是否相邻
            bool is_adjacent = binary_search(e[u].begin(), e[u].end(), v);
            
            // 终极公式应用
            int current_components = deg[u] + deg[v] - (is_adjacent ? 2 : 1);
            max_ans = max(max_ans, current_components);
        }
        
        // 外层剪枝：如果当前排第一的 u 和排第二的点加起来的理论极限都不行了，外层循环直接收工
        if (i + 1 < n && deg[u] + deg[id[i+1]] - 1 <= max_ans) {
            break;
        }
    }

    cout << max_ans << "\n";
}

int main()
{
    IOS
    int _ = 1;
    cin >> _;
    while(_--)
        solve();
    return 0;
}
```

## 💡 总结与反思

1. **物理删除的代价**：在最初的思路里，我们执着于用 `swap + pop_back` 物理删边来模拟过程。实际上在图论题目中，如果能**通过数学公式将操作抽象化（例如本题转换为度数减法）**，就可以完全避免去改动图的结构，不仅不容易写出 Bug，效率也会发生质的飞跃。
    
2. **警惕分步贪心**：当题目要求“同时选择两个元素”或“执行两次操作”来最大化收益时，**先后各选最优 $\neq$ 组合整体最优**。时刻注意元素之间的内在关联（例如本题中两点是否相邻会引发度数连锁反应）。
    
3. **善用排序和剪枝**：双重循环看似 $O(n^2)$，但是只要数据具有单调性（如度数从大到小），利用上限阻断（`if (上限 <= max_ans) break;`）往往能将大范围的无用枚举直接抹去，是赛时保底、冲高分的绝对利器。
