> 🔗 **原题链接**：[Problem - 2233C - Codeforces](https://codeforces.com/problemset/problem/2233/C)
题意：给定一个括号字符串
“代价”定义为其中最长的正规括号子序列的长度
你的任务是最多删除 k 个字符，使得删除后的字符串的代价尽可能小
思路：
1. 暴力 我们每次暴力找左右两边删掉之后也没有能减少方案数量的，有就删掉，时间复杂度为$O(n*k)$
2. 我们可以找到一个平衡点使得 
$M=min⁡_{i=0,n}(pref_{openi}+suff_{closei}))$
我们令满足条件的i为$pos$
我们可以发现 $pos$ 左边的右括号数量一定大于左括号数量，且 $pos$ 右边一定不会出现这个情况，因为出现了即右边存在一个负数，即可以找到一个更小的M，于是我们可以说右边的左括号数量一定大于右括号，所以我们发现， $pos$ 左边贪心的删掉左括号一定可以减少代价，右边同理。
```cpp
void solve()
{
	int n,k;
	cin>>n>>k;
	string s,ans;
	cin>>s;
	int pos = -1,cnt=0,minn=INT_MAX/2;
	for(int i=0;i<n;i++)
	{
		if(s[i]=='(') cnt++;
		else cnt--;
		if(cnt<minn&&cnt<0) pos = i,minn = cnt;
	}
	for(int i=0;i<=pos;i++) 
	{
		if(k&&s[i]=='(') k--,ans.push_back('1');
		else ans.push_back('0');
	}
	for(int i=pos+1;i<n;i++) 
	{
		if(k&&s[i]==')') k--,ans.push_back('1');
		else ans.push_back('0');
	}
	cout<<ans<<endl;
}
```
