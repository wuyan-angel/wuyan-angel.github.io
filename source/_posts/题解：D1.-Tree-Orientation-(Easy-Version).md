# 题解：D1. Tree Orientation (Easy Version)

本题的核心任务是：**给定一个有向图的可达性矩阵（传递闭包），还原出原本的有向树结构。** 以下为你整理了两种解决该问题的经典方法：**$O(n^3)$ 的传递约简法**（适合基础通解）以及 **$O(n^2)$ 的拓扑层级贪心法**（高级优化，可通关 Hard Version）。

## 核心前置性质

在有向树中，任意两个节点之间的底层无向路径是**唯一**的。这导出了两个关键结论：

1. **唯一性**：如果存在合法解，这个有向树的结构必然是唯一的。
    
2. **直接边定义**：如果 $u$ 能到达 $v$，且不存在任何中转点 $w$ 满足 $u \to w \to v$，那么 $u \to v$ 必然是树上的一条**直接边**。
    

## 方法一：传递约简法（Transitive Reduction）

### 1. 核心思路

传递约简（Transitive Reduction）是指在一个有向无环图中，**去掉所有“间接可达”的边，只保留“直接连接”的边**。对于树而言，其传递约简的结果就是树的本身。

### 2. 算法步骤

1. **合法性检查**：
    
    - **自反性**：检查是否所有 $s_{i,i} = 1$。
        
    - **反对称性**：若 $i \neq j$，不能同时有 $s_{i,j}=1$ 和 $s_{j,i}=1$（不能有环）。
        
    - **传递性**：若 $s_{i,j}=1$ 且 $s_{j,k}=1$，必须有 $s_{i,k}=1$。
        
2. **提取树边**：枚举所有满足 $s_{u,v}=1$ ($u \neq v$) 的点对。遍历所有其他点 $w$，如果找不到任何一个 $w$ 满足 $s_{u,w}=1$ 且 $s_{w,v}=1$，说明 $u \to v$ 是一条直接边，加入答案。
    
3. **树判定**：检查提取出的边数是否恰好为 $n-1$，且整体无向连通。
    

### 3. 复杂度分析

- **时间复杂度**：$O(n^3)$。由于需要枚举 $u, v, w$ 三个点来确认一条边是否为直接边。
    
- **空间复杂度**：$O(n^2)$。用于存储邻接矩阵。
    

## 方法二：拓扑层级贪心法（剥洋葱法）

### 1. 核心定理与证明

- **定义**：令 $R_u$ 为 $u$ 能到达的**其他**节点集合；$s_u$ 为 $u$ 能到达的节点总数（包含自己，即 $s_u = |R_u| + 1$）。
    
- **定理**：**在 $u$ 的可达集合 $R_u$ 中，可达总数 $s_v$ 最大的那个节点 $v$，必然是 $u$ 的直接儿子（即存在直接边 $u \to v$）。**
    

> **证明（反证法）**：
> 
> 假设 $v$ 不是 $u$ 的直接儿子，则在有向树中， $u$ 到 $v$ 的路径上必然隔着一个中间节点 $w$（即 $u \to \dots \to w \to \dots \to v$）。
> 
> 既然 $w$ 能到达 $v$，那么 $w$ 的可达集合不仅包含 $v$ 及其后代，还包含 $w$ 自己以及 $w \to v$ 路径上的其他点。
> 
> 因此，必然有 $s_w > s_v$。这与“$v$ 是 $R_u$ 中 $s$ 最大的点”这一前提相矛盾。故假设不成立，$u \to v$ 必须是直接边。

### 2. 算法步骤

1. **预处理**：统计每个点的 $s_u$（即输入矩阵中每行 `1` 的数量），并将所有节点按照 $s_u$ **从大到小排序**。
    
2. **贪心剥离**：对于每个节点 $u$：
    
    - 按排序后的顺序遍历 $R_u$ 中的点。碰到的第一个未被标记的能到达的点 $v$，必定是 $s_v$ 最大的点。
        
    - 确定直接边 $u \to v$。
        
    - **集合擦除**：将 $v$ 能够到达的所有后代节点 $w$ 全部在 $u$ 的后续遍历中标记为“已剥离”（因为它们可以通过 $v$ 间接到达，不可能再与 $u$ 连直接边）。
        
3. **两关验证**：
    
    - **结构关**：用并查集检查总边数是否为 $n-1$ 且全图连通。
        
    - **防伪关**：在建好的树上跑一遍 DFS，重新计算可达矩阵，检查是否与原输入矩阵完全一致。
        

### 3. 完整实现代码（C++）

C++

```
#include <bits/stdc++.h>
using namespace std;

constexpr int N = 505;
int n, id[N], cnt[N];
bool vs[N], e[N][N];
bool reach[N];
vector<int> tree[N];

// 并查集结构用于连通性检查
struct Dsu {
    int fa[N];
    void init(int n) { for (int i = 1; i <= n; i++) fa[i] = i; }
    int find(int x) { return x == fa[x] ? x : fa[x] = find(fa[x]); }
    void merge(int x, int y) { fa[find(x)] = find(y); }
} dsu;

// DFS 还原可达性
void search(int u) {
    reach[u] = true;
    for (int v : tree[u]) search(v);
}

void solve() {
    cin >> n;
    // 初始化
    for (int i = 1; i <= n; i++) cnt[i] = 0, tree[i].clear();
    
    // 1. 读取矩阵并统计每个点的可达总数 cnt
    for (int u = 1; u <= n; u++) {
        id[u] = u;
        string s;
        cin >> s;
        for (int v = 1; v <= n; v++) {
            e[u][v] = s[v-1] - '0';
            cnt[u] += e[u][v];
        }
    }
    
    // 按可达总数从大到小排序
    sort(id + 1, id + n + 1, [&](int u, int v) {
        return cnt[u] > cnt[v];
    });

    // 2. 贪心提取直接边
    vector<pair<int, int>> edges;
    for (int u = 1; u <= n; u++) {
        for(int i = 1; i <= n; i++) vs[i] = false;
        vs[u] = true; // 排除自己
        
        for (int i = 1; i <= n; i++) {
            int v = id[i];
            // 如果 v 未被间接覆盖，且 u 能到达 v
            if (!vs[v] && e[u][v]) {
                edges.push_back({u, v});
                if(edges.size() >= n) { cout << "No\n"; return; }
                
                // 擦除：将 v 的所有子孙节点标记，防止 u 重复连接
                for (int w = 1; w <= n; w++) {
                    if (e[v][w]) vs[w] = true;
                }
            }
        }
    }

    // 3. 验证第一关：边数判定
    if (edges.size() != n - 1) { cout << "No\n"; return; }

    // 4. 验证第二关：连通性判定
    dsu.init(n);
    for (auto [u, v] : edges) {
        dsu.merge(u, v);
        tree[u].push_back(v); // 建立有向树
    }
    int is_connected = 1;
    for (int i = 1; i <= n; i++) is_connected &= (dsu.find(i) == dsu.find(1));
    if (!is_connected) { cout << "No\n"; return; }

    // 5. 验证第三关：终极防伪（DFS 还原比对）
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) reach[j] = false;
        search(i);
        for (int j = 1; j <= n; j++) {
            if (reach[j] != e[i][j]) { cout << "No\n"; return; }
        }
    }

    // 构造成功
    cout << "Yes\n";
    for (auto [u, v] : edges) {
        cout << u << ' ' << v << '\n';
    }
}

int main() {
    ios::sync_with_stdio(0), cin.tie(0);
    int T;
    cin >> T;
    while (T--) solve();
    return 0;
}
```

## 两种方法对比总结

|**指标**|**方法一：传递约简法**|**方法二：拓扑层级贪心法**|
|---|---|---|
|**核心原理**|暴力枚举并剔除有中转点的间接边|按可达数降序排序，贪心剥离最大子树|
|**时间复杂度**|$O(n^3)$|$O(n^2)$|
|**编程难度**|较低，逻辑直接|中等，需配合排序与标记擦除|
|**版本适用度**|仅能通过 Easy Version ($n \le 500$)|能轻松通过 Easy 和 Hard Version|
