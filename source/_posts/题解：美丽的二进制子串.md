# 题解：美丽的二进制子串

## 一、题目大意

给定一个长度为 $n$ 的二进制串 $s$，定义两种操作：

- $00 \to 1$（两个相邻的 0 合并成一个 1）
- $11 \to 0$（两个相邻的 1 合并成一个 0）

每次操作长度减少 1。如果一个串能通过若干次操作变成**长度为 1** 的串，就称它是"美丽的"。

问 $s$ 有多少个**子串**是美丽的。

---

## 二、先抓住一个不变量：$f \bmod 3$

定义

$$
f(t) = (1\text{ 的个数}) - (0\text{ 的个数})
$$

看两种操作对 $f$ 的影响：

| 操作 | 操作前 $f$ | 操作后 $f$ | 变化量 |
|---|---|---|---|
| $00\to 1$ | $-2$ | $+1$ | $+3$ |
| $11\to 0$ | $+2$ | $-1$ | $-3$ |

**所以每次操作 $f$ 的变化量都是 $3$ 的倍数，即 $f \bmod 3$ 永远不变。**

最终变成长度 $1$ 的串，要么是 `0`（$f=-1$），要么是 `1`（$f=+1$），它们的 $f\bmod 3$ 分别是 $2$ 和 $1$，**都不是 $0$**。

因此必要条件：

$$
f(t) \not\equiv 0 \pmod 3
$$

另外，如果一个长度大于 $1$ 的串是**交错的**（相邻字符全部不同，如 `0101`），那它根本不含 `00` 或 `11`，一步操作都做不了，当然不美丽。

---

## 三、充要条件

一个非空二进制串 $t$ 是美丽的，当且仅当：

1. $f(t)\not\equiv 0 \pmod 3$；
2. $t$ 不是长度大于 $1$ 的交错串。

必要性前面已经说明，下面重点讲**充分性**（这也是题解里最绕的地方）。

---

## 四、充分性证明（重点，问题 2）

我们要证明：满足上面两个条件的串，一定能一步步归约到长度 1。

### 整体思路：归纳

只要串长度还大于 1，我们就希望**做一步操作后，两个条件仍然保持**：

- $f\bmod 3$：自动保持（因为操作不改变它）；
- 非交错：这是需要动脑筋的地方。

只要每次操作后"仍然不是交错的"，就能一直操作下去，直到长度变成 1。

所以核心是证明一个引理：

> **引理**：一个长度大于 1、且非交错的串，一定存在一步操作，使得操作后**仍然非交错**（或直接变成长度 1）。

### 证明引理：按"极大相等块"分类

把串按连续相同字符切成若干**极大块**（比如 `00100` 切成 `00 / 1 / 00`）。

因为串非交错，所以至少有一个极大块长度 $\ge 2$。分三类讨论。

---

#### 情况 A：存在长度为 2 的块

设这个块是 `aa`（$a$ 是 0 或 1），它两边如果有邻居，邻居一定是相反字符 $b = 1-a$。

我们对 `aa` 操作：`aa → b`。

- 若左右都有邻居：`…b aa b…` 变成 `…b b b…`，出现了相邻 `bb`；
- 若只有一边邻居：`…b aa` 变成 `…b b`，也有相邻 `bb`；
- 若整个串就是 `aa`（长度 2）：操作后变成单个 `b`，直接到长度 1。

所以只要还没到长度 1，操作后一定有相邻相等字符，**仍然非交错**。

例子：`1001` 中 `00` 是长度 2 的块，操作后变成 `111`，仍非交错。

---

#### 情况 B：没有长度为 2 的块，但存在长度 ≥ 3 的块

也就是说，所有长度 ≥ 2 的极大块都至少长 3。取一个这样的块 `aaa…`（至少 3 个 $a$）。

##### 子情况 B1：这个块不是整个串

那它至少有一边有邻居 $b = 1-a$。

我们操作**紧挨着 $b$ 的那两个 $a$**（靠边界的那两个）：

$$
\cdots b\ a\ a\ a\cdots \ \longrightarrow\ \cdots b\ b\ a\cdots
$$

插入的 $b$ 和边界外的 $b$ 形成了相邻的 `bb`，所以仍然非交错。

例子：`10001` 中 `000` 长度 3，操作前两个 0 得 `1101`，有 `11`。

##### 子情况 B2：整个串全是同一种字符 $a^m$

此时 $f = \pm m$，而 $f\bmod 3 \neq 0$，所以 $m$ 不是 3 的倍数。

$m=1$ 已经到长度 1；$m=2$ 属于情况 A（`aa` 直接变成长度 1）。剩下的 $m \ge 4$。

在端点操作两个 $a$：`aaa…a` → `b aa…a`，剩下 $m-2 \ge 2$ 个 $a$，仍有相邻 `aa`，非交错。

---

三种情况覆盖了所有可能性，引理成立，充分性证毕。

> 直观总结：**只要串不是交错的，就总能挑一个"位置合适"的相邻相等对来操作，使得操作后还留下相邻相等对**，从而不会卡死。于是可以一路操作到长度 1。

---

## 五、计数：数美丽子串

现在目标：数 $s$ 中满足

1. $f \not\equiv 0 \pmod 3$；
2. 不是长度大于 1 的交错串。

的子串个数。

### 第一步：用前缀处理 $f \bmod 3$

给字符赋权：`1` 记 $+1$，`0` 记 $-1$。定义前缀

$$
p_i = \sum_{j=1}^{i} val(s_j) \pmod 3,\qquad p_0 = 0
$$

子串 $s[l..r]$ 的 $f \bmod 3 = (p_r - p_{l-1})\bmod 3$。

所以

$$
f(s[l..r])\not\equiv 0 \pmod 3
\iff p_r \neq p_{l-1}
$$

从左到右扫描，维护 `cnt[0..2]` 表示**此前出现过的前缀值**各有多少个，初始 `cnt[0]=1`（空前缀）。

设当前右端点的前缀值为 $x=p_r$，则以 $r$ 结尾、满足 $f\not\equiv0\pmod 3$ 的子串个数是：

$$
\underbrace{(cnt[0]+cnt[1]+cnt[2])}_{\text{前面一共有多少个 } l-1}
-\underbrace{cnt[x]}_{\text{其中和 } p_r \text{ 同值的}}
$$

这算出来的是"满足条件 1"的子串个数。但它把**长度大于 1 的交错子串**也算了进来，需要减掉。

---

### 第二步：减去交错子串（重点，问题 1）

设 $y$ 为**以当前位置 $r$ 结尾的最长交错后缀**的长度。

**关键结论：以 $r$ 结尾的交错子串，恰好就是长度 $1,2,\dots,y$ 这 $y$ 个。**

为什么？最长交错后缀是 $s[r-y+1..r]$，它是一个交错串；交错串的**任意后缀**还是交错的，所以长度 $1$ 到 $y$ 的子串都是交错的；而再往前多取一个字符（长度 $y+1$）就会破坏交错性（因为 $y$ 已经是"最长"），所以不可能有更长、更靠左的交错子串。

接下来看这些交错子串的 $f$ 值：

- **偶数长度**的交错串（如 `01`、`0101`）：$0$ 和 $1$ 各占一半，$f=0$，于是 $f\bmod 3 = 0$，**在第一步的"前缀计数"里根本就没被算进去**，所以不用减。
- **奇数长度**的交错串（如 `0`、`010`）：$f=\pm 1$，$f\bmod 3\neq 0$，**在第一步被算进去了**。

其中：

- 长度为 $1$ 的（单个字符）是**美丽**的，要保留；
- 长度为 $3,5,7,\dots$ 的奇数长度交错串，是"长度大于 1 的交错串"，**不美丽**，必须减去。

所以每个位置要减掉的数量 = 在 $1,2,\dots,y$ 中，**大于等于 3 的奇数**的个数。

列表对照：

| $y$ | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 要减掉的个数 | 0 | 0 | 1 | 1 | 2 | 2 | 3 | 3 |

这个个数就是

$$
\left\lfloor \frac{y-1}{2} \right\rfloor
$$

验证：$y=3$ 时 $\lfloor 2/2\rfloor=1$；$y=4$ 时 $\lfloor 3/2\rfloor=1$；$y=5$ 时 $\lfloor 4/2\rfloor=2$，完全吻合。

> 这就是题解里 `(y-1)/2` 的来历：它**只数了长度为 3,5,7,… 的奇数交错子串**，偶数长度的没被算进来，长度为 1 的保留。

`y` 的维护很简单：

- 如果当前字符和上一个字符**不同**，则交替后缀可以延长，$y \gets y+1$；
- 如果**相同**，则交替后缀断掉，$y \gets 1$。

---

## 六、每个位置的贡献

综上，以 $r$ 结尾的美丽子串个数为：

$$
\Big(cnt[0]+cnt[1]+cnt[2]-cnt[p_r]\Big)
-\left\lfloor \frac{y-1}{2} \right\rfloor
$$

把所有位置累加就是答案。

---

## 七、代码

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

int main() {
    int n;
    string s;
    cin >> n >> s;

    ll ans = 0;          // 注意从 0 开始累加
    int now = 0;         // 当前前缀 p_i mod 3
    ll y = 1;            // 以当前位置结尾的最长交错后缀长度
    vector<ll> cnt(3, 0);
    cnt[0] = 1;          // 空前缀 p_0 = 0

    for (int i = 0; i < n; i++) {
        // 更新前缀 mod 3
        now = (now + (s[i] == '1' ? 1 : -1)) % 3;
        if (now < 0) now += 3;

        // 维护最长交错后缀长度
        if (i) {
            if (s[i] != s[i - 1]) y++;
            else y = 1;
        }

        // 条件 1：f mod 3 != 0
        ans += cnt[0] + cnt[1] + cnt[2] - cnt[now];
        cnt[now]++;

        // 条件 2：减掉长度为 3,5,7,... 的交错子串
        ans -= (y - 1) / 2;
    }

    cout << ans << '\n';
    return 0;
}
```

---

## 八、复杂度

- 时间：$O(n)$，每个字符只处理常数次。
- 空间：$O(1)$。

---

## 九、小结

1. 操作不改变 $f\bmod 3$，且最终 $f=\pm1$，所以必要条件 $f\not\equiv0\pmod3$。
2. 交错串（长度 >1）无法操作，所以也要排除。
3. 这两个条件**恰好充分**：只要串非交错，就总能做一步操作保持"非交错"，一路归约到长度 1。
4. 计数时先用前缀差 $p_r\neq p_{l-1}$ 数出条件 1，再减去被误算进来的、长度为 $3,5,7,\dots$ 的奇数交错子串，个数是 $\lfloor (y-1)/2\rfloor$。
