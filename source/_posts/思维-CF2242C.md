## 问题理解

**给定**：一个已排序数组 a，长度 n

**操作**：每次操作分两步
1. **标记**：标记第一个元素 + 所有不同于左边邻居的元素
2. **选择**：要么**删除**所有标记元素，要么**复制**所有标记元素（每个变两个）

**问**：有多少种不同的数组 b，长度为 k，可以通过若干次操作得到？

---

## 第一步：标记规则在做什么？

因为数组已排序，相同值连续出现。标记的就是**每段连续相同值的第一个**。

```
例子：[1, 1, 1, 2, 4, 4, 5]
标记： ↑        ↑  ↑     ↑
      第1个   2≠1 4≠2  5≠4
```

**标记个数 = 不同值的个数**，记为 `kd`。
**没标记的个数** = n - kd。

---

## 第二步：操作对数组的影响

**删除标记元素** → 每段连续值少了一个（第一个被删了）
```
[1,1,1, 2, 4,4, 5]  →  [1,1, 4]
长度: n → n - kd
那些只有一个的值会彻底消失（kd 可能减少）
```

**复制标记元素** → 每段连续值的第一个变两个
```
[1,1,1, 2, 4,4, 5]  →  [1,1,1,1, 2,2, 4,4,4, 5,5]
长度: n → n + kd
kd 不变（所有值都还在）
```

**核心观察**：每一次操作，就是**每个不同值的个数同时 +1 或同时 -1**。

因为数组已排序，这些值彼此独立，不会合并也不会分裂。

---

## 第三步：关键结论

既然每次操作影响所有值：

- DELETE 操作：每个值的剩余个数 -1（个数变 0 的消失）
- DUPLICATE 操作：每个值的剩余个数 +1

**重要性质**：先做 DELETE 再做 DUPLICATE，等价于任何交错顺序。

为什么？因为如果先 DUPLICATE 再 DELETE：
> 长度增大又减小，回到原点，没变化

但**先 DELETE 再 DUPLICATE**：
> 有些值可能在 DELETE 阶段消失了，DUPLICATE 不会把它们变回来

所以，任何操作序列都可以看作：
```
先做 x 次 DELETE → 再做 p 次 DUPLICATE
```

---

## 第四步：数学化

对于给定的 x（DELETE 次数）：

**哪些值被摧毁了？**
- 原始个数 ≤ x 的值 → 完全消失
- 原始个数 > x 的值 → 剩余个数 = 原始个数 - x

**记：**
- `d` = 被摧毁值的总个数之和
- `q` = 幸存的不同值个数（kd'）
- 幸存值当前的**总个数** = `n - d - x·q`

> 解释：n 是原始总个数，d 是被摧毁的总个数，x·q 是每个幸存值被删了 x 次

**然后再做 p 次 DUPLICATE：**
- 每次增加 q 个元素
- 最终长度 = `(n - d - x·q) + p·q`

**目标长度 k：**
```
k = n - d - x·q + p·q
→ k - (n - d - x·q) = p·q
→ (k - remaining) % q == 0  且  remaining ≤ k
```

其中 `remaining = n - d - x·q`

---

## 第五步：避免重复计数

不同的 x 可能给出**相同的数组**，因为摧毁的是同一组值。

```
例如，没有值个数为 2：
x=1 和 x=2 摧毁的是同一批值（个数 ≤1 的那些）
所以得到的最终数组是一样的
```

规则：**只检查那些 x 值，使得 x+1 刚好摧毁一个新块**。

也就是：**只检查 cnt[x+1] > 0 的 x**（存在原始个数为 x+1 的值）

再加上 x=0 也检查。

---

## 第六步：完整算法

```
1. 扫描数组，统计每个值的连续出现次数
   cnt[s] = 出现次数 = s 的值有几个

2. 预处理前缀和
   pref_sum[s] = 出现次数 < s 的值的总个数
   pref_cnt[s] = 出现次数 < s 的值的个数

3. 枚举 x:
   for x = 0:  直接检查
   for x = 1..n: 只当 cnt[x+1] > 0 时检查

   检查函数 check(x):
     d = pref_sum[x+1]         // 被摧毁的总个数
     q = total_blocks - pref_cnt[x+1]  // 幸存值个数
     如果 q == 0 → 跳过（数组为空）
     remaining = n - d - x·q
     如果 remaining > k → 跳过（做 DUPLICATE 只能增加长度）
     如果 (k - remaining) % q == 0 → 答案 +1
```

---

## 第七步：图解样例

**样例：** `n=8, k=6, a=[1,1,1,2,2,2,2,2]`

```
块大小: 值1出现3次, 值2出现5次
cnt[3]=1, cnt[5]=1

x=0: remaining=8 > 6, 跳过

x=2 (因为 cnt[3]>0):
  d = 0（没有出现次数<3的）
  q = 2
  remaining = 8 - 0 - 2·2 = 4
  4 ≤ 6, (6-4)%2=0 → ✅ 得到 [1,1,2,2,2,2]

x=4 (因为 cnt[5]>0):
  d = 3（值1个数3被摧毁）
  q = 1（只剩值2）
  remaining = 8 - 3 - 4·1 = 1
  1 ≤ 6, (6-1)%1=0 → ✅ 得到 [2,2,2,2,2,2]
```

答案 = 2，对应题目的 Note 中给出的两个数组。
