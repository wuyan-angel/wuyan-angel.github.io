# 最大化最坏收益 — 策略选择问题

## 问题描述

有 $n$ 个已知报价 $a_1, a_2, \dots, a_n$，真实价格 $p \in [l, r]$ 未知。

对每个 $a_i$，在知道 $p$ 之前**固定**选择：

| 颜色 | 含义 | 收益 |
|------|------|------|
| 🔴 红色 | 赌 $p$ 更大 | $p - a_i$ |
| 🔵 蓝色 | 赌 $p$ 更小 | $a_i - p$ |
| ⚪ 白色 | 忽略 | $0$ |

并且红色一定取在左边 蓝色一定取右边
直觉上来说我们可以画一个线段
![](/images/vault/Pasted-image-20260723111045.png)
此时我们发现无论P落在任何点收益都是大于等于0的
形式化的证明我们可以直接看当 $$x<y,p-x+y-p>=p-y+x-p$$
因此 前面一定取小于P，后面一定取大于P

目标：最大化**最坏情况下的总收益**。

---

## 核心思路

### 1. 收益是线性函数

设红色 $R$ 个，蓝色 $B$ 个，红之和 $S_R$，蓝之和 $S_B$：

$$
\text{Profit}(p) = (R - B)\cdot p + (S_B - S_R)
$$

直线函数，最坏值一定在端点：

$$
\text{最坏收益} = \min\big(\text{Profit}(l),\ \text{Profit}(r)\big)
$$

### 2. 最优策略的形态（交换论证）

**排序**后 $a_1 \le a_2 \le \dots \le a_n$。

> ✅ **结论 1**：红色是前缀（左边小的），蓝色是后缀（右边大的），白色在中间。

> ✅ **结论 2**：白色最多一个。

**证明（交换论证）：**
- 若 $x < y$ 且 $x$ 白、$y$ 红 → 交换为 $x$ 红、$y$ 白，收益增加 $y - x \ge 0$。
- 若 $x < y$ 且 $x$ 蓝、$y$ 白 → 交换为 $x$ 白、$y$ 蓝，收益增加 $y - x \ge 0$。

对两个白色：白 $a_i \le a_j$ → 改为 $a_i$ 红、$a_j$ 蓝，收益增加 $a_j - a_i \ge 0$。

### 3. 参数的数学表示

排序后前缀和 $\text{sum}[i] = a_1 + \dots + a_i$。

固定：
- 红色个数 $x$（$0 \le x \le n$）
- 白色结束位置 $y$（$x \le y \le n$，$y = x$ 表示无白色）

总收益：

$$
S(p) = (x + y - n)\cdot p + \big(\text{sum}[n] - \text{sum}[y] - \text{sum}[x]\big)
$$

最坏收益：

$$
F(x, y) = \min\big(S(l),\ S(r)\big)
$$

---

## 方法一：三分法 🔍

### 单峰性证明

固定 $x$，考察 $S_l(y) = S(l)$ 和 $S_r(y) = S(r)$：

$$
\begin{aligned}
S_l(y+1) - S_l(y) &= l - a_{y+1} \\
S_r(y+1) - S_r(y) &= r - a_{y+1}
\end{aligned}
$$

因为 $a$ 递增，所以 $S_l, S_r$ 各自单峰（先增后减）。

两者差：

$$
S_r(y) - S_l(y) = (r-l)(x + y - n)
$$

是 $y$ 的线性增函数，存在唯一交点。  
$\min(S_l, S_r)$ 由 $S_r$ 左半和 $S_l$ 右半拼接而成，**整体单峰**。

### 算法

```python
def solve():
    sort(a)
    预处理前缀和 sum[]
    ans = -inf
    for x in range(0, n+1):
        # 三分 y ∈ [x, n]
        lo, hi = x, n
        while hi - lo > 3:
            m1 = lo + (hi - lo) // 3
            m2 = hi - (hi - lo) // 3
            if F(x, m1) < F(x, m2):
                lo = m1
            else:
                hi = m2
        for y in range(lo, hi+1):
            ans = max(ans, F(x, y))
    return ans
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void solve() {
    int n; ll l, r;
    cin >> n >> l >> r;
    vector<ll> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    sort(a.begin(), a.end());

    vector<ll> sum(n + 1, 0);
    for (int i = 0; i < n; ++i) sum[i+1] = sum[i] + a[i];

    ll ans = LLONG_MIN;

    for (int x = 0; x <= n; ++x) {
        // 无白色
        {
            ll s_l = x * l - sum[x] + (sum[n] - sum[x]) - (n - x) * l;
            ll s_r = x * r - sum[x] + (sum[n] - sum[x]) - (n - x) * r;
            ans = max(ans, min(s_l, s_r));
        }
        // 一个白色在 x+1
        if (x + 1 <= n) {
            ll s_l = x * l - sum[x] + (sum[n] - sum[x+1]) - (n - x - 1) * l;
            ll s_r = x * r - sum[x] + (sum[n] - sum[x+1]) - (n - x - 1) * r;
            ans = max(ans, min(s_l, s_r));
        }
    }

    cout << ans << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int t; cin >> t;
    while (t--) solve();
    return 0;
}
