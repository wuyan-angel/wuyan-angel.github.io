1.逆元的定义：若整数b与m互质，如果满足b|a，则存在一个整数使得a/b(mod m)=ax(mod m)，此时x为b的一个逆元。

2.费马小定理：对于一个质数p有 a^p-1(mod p) = 1(mod p)
于是通过以上定理 假设已知b与m，且m为质数，则可以通过1，2两个知识点快速求出b的一个逆元为b的p-2次方mod p。下面给出详细推导过程(以下等于请视为同余)

$a/b=a*x(mod p) ---> a/b=a*b^{-1}(mod p)$
$b^{-1}*b = 1(mod p) ---> b^{-1} =b^{p-2}(mod p)$
最终b^-1 = b^p-2 (mod p) 且b不能是p的倍数  
由上可知 已知a和p，p为质数，求a模p的乘法逆元为a^p-2

扩展欧几里得解的推导
首先我们知道普通的欧几里得
```c++
int gcd(inta ,int b)
{
	return b?a:gcd(b,a%b);
}
```
有裴蜀定理可以知道 必有一组x和y满足 $ax+by = gcd(a,b)$
已知方程
$ax+by=gcd(a,b) = gcd(b,a\%b) = bx_1+(a\%b)y_1.$
可以通过 $a\%b =(a- a/b)*y_1$ 替换第二个式子，则有以下式子
$x = y_1, y =(x_1-a/b*y_1 )$
通过不断递归到b等于0的时候 此时给出条件y=1,x=0即可
最后通过递归解出X,Y

以上是用于解出$ax+by = gcd(a,b)$的x和y的特解的
下面给出ax+by=c的特解方法（前提：c%gcd(a,b)\=\=0,即$gcd(a,b)|c)$
此时$ax+by=c$ 相当于$ax+by=gcd(a,b)$两边同时除以了$c/gcd(a,b)$
于是特解就为$x = x1*c/gcd(a,b), y = y1*c/gcd(a,b)$


扩欧代码如下：
```c++
ll exgcd(ll a,ll b,ll &x,ll &y)
{
	if(!b)
	{
		x = 1;
		y = 0;
		return a;
	}
	ll gcd,x1,y1;
	gcd = exgcd(b,a%b,x1,y1);
	x=y1,y=(x1-a/b*y1);
	return gcd;
}
```
