> 🎯 **一句话题意**：给定 N×M 高度地图，水只能从高流向低，求覆盖最后一行的最少水库数或无解时的未覆盖格数。

---

这是一道经典题目 **「引水入城」**（洛谷 P1514），我用最通俗的方式给你讲一遍。

---

## 一、题目回顾

你有一个 N 行 × M 列的矩形地图，每个格子有高度。

```
规则：水只能从高流向低，相邻格子间如果高度差 > 0，水可以流过去

你可以做的：在第一行（x=1）的任意格子上「建水库」放水
你的目标：让最后一行（x=N）的每个格子都有水

输出：
  情况1（能）→ 输出 1，另起一行输出最少需要建几个水库
  情况2（不能）→ 输出 0，另起一行输出最后一行有几个格子没水
```

示意图：

```
第1行：  [水] [水] ...        ← 你可以选择在哪些格子建水库
第2行：  ... ... ...
  ...
第N行：  [✓] [✓] [✗] [✓] [✓]  ← 目标：全部 [✓]
```

---

## 二、第一步：判断有无解

从第一行的 **每个格子** 出发做一次搜索（DFS/BFS），标记能流到哪些格子。最后看最后一行有多少格子没被标记。

```python
# 伪代码
for 第一行的每个格子 j:
    从 (0, j) 出发做搜索，标记全部能到达的格子

count = 0
for 最后一行每个格子 j:
    if 没被标记:
        count += 1
if count > 0:
    输出 0
    输出 count
    结束
```

这不是重点，重点是下面。

---

## 三、核心定理（为什么一定是连续区间）

**定理**：如果整体有解（最后一行全覆盖），那么第一行的每个格子，它所能覆盖的最后一行格子 **必定是一个连续的区间**。

通俗说：一个水库的水流到最后一行，覆盖的格子一定是一段挨在一起的，不会有「中间漏一个两边有」的情况。

### 证明（反证法）

假设整体有解，但某个水库 A 覆盖的最后一行不连续：

```
最后一行：  ■  ■  □  ■  ■
            └────┘  └────┘
            A覆盖   A覆盖
              中间这个漏了
```

- A 覆盖了位置 i 和 k，但中间位置 j 没覆盖到
- 既然整体有解，位置 j 必定被另一个水库 B 覆盖
- 那么 B 的水从第一行流到了位置 j

**关键**：考虑 A 的水流路径和 B 的水流路径

```
第1行:     A             B
         ╱                  ╲
        ╱         交汇点       ╲
       ╱     ×××××××××××××   ╲
      i          j           k
```

两条路径必在地图某处相交！（因为 A 要去 i 和 k，B 要穿过 A 的路线到达 j）

既然相交，A 的水到了那个交点，就可以沿着 B 的路继续流到 j，这就推出了 **A 也能覆盖 j**！与假设矛盾。

因此且仅当整体有解时，每个水库覆盖的是一个连续区间。

---

## 四、第二步：算出每个水库的区间

对第一行每个格子做搜索，但这次不仅标记到达，还要记录 **能到达的最后一行最左列 L 和最右列 R**。

```python
def dfs(x, y, visited):
    if (x, y) 已搜索过:
        return 已记录的结果
    
    if x == n-1:  # 到了最后一行
        return y, y  # 最左和最右都是自己
    
    left, right = m, -1
    for 四个方向:
        nx, ny = 下一个格子
        if 可以流向 (nx, ny):
            l, r = dfs(nx, ny, visited)
            left = min(left, l)
            right = max(right, r)
    
    return left, right
```

这样第一行每个格子 j 对应一个区间 [L[j], R[j]]。

---

## 五、第三步：最少区间覆盖线段

现在问题转化为：

> 有 M 列，给你 K 个区间 [L₁,R₁] [L₂,R₂] ... [Lₖ,Rₖ]，选最少的区间数，覆盖 1 到 M 所有列。

这是经典的贪心：

```
算法：
1. 按左端点从小到大排序
2. current = 1（当前还没覆盖到的最左列）
3. i = 0
4. 答案 = 0
5. while current <= M:
       best_right = 0
       把所有左端点 <= current 的区间，取它们右端点的最大值
       if 找不到:
           无解
       current = best_right + 1
       答案 += 1
```

**举例**：

```
M = 5
区间： [1,2]  [1,3]  [2,4]  [3,5]

排序后一样

current = 1:
  左端点<=1的有: [1,2]右端点2, [1,3]右端点3 → best = 3
  选[1,3], current = 4, ans = 1

current = 4:
  左端点<=4的有: [2,4]右端点4, [3,5]右端点5 → best = 5
  选[3,5], current = 6, ans = 2

覆盖完成，最少2个
```

注意：上面区间覆盖的时候，L ≤ current 的条件应该是 **L ≤ current**（因为可以重叠），不是 L ≤ current+1。

---

## 六、复杂度

- 搜索每个格子带记忆化：O(N × M)
- 区间排序：O(M log M)
- 贪心：O(M)

总体：O(N × M + M log M)

---

## 七、核心代码框架

```python
import sys
sys.setrecursionlimit(1000000)

n, m = map(int, input().split())
h = [list(map(int, input().split())) for _ in range(n)]

# 方向
dx = [0, 0, 1, -1]
dy = [1, -1, 0, 0]

# 记忆化搜索
vis = [[False] * m for _ in range(n)]
L = [[-1] * m for _ in range(n)]
R = [[-1] * m for _ in range(n)]

def dfs(x, y):
    if vis[x][y]:
        return L[x][y], R[x][y]
    vis[x][y] = True
    if x == n - 1:
        L[x][y] = R[x][y] = y
    else:
        left, right = m + 1, -1
        for k in range(4):
            nx, ny = x + dx[k], y + dy[k]
            if 0 <= nx < n and 0 <= ny < m:
                if h[x][y] > h[nx][ny]:
                    nl, nr = dfs(nx, ny)
                    left = min(left, nl)
                    right = max(right, nr)
        L[x][y] = left
        R[x][y] = right
    return L[x][y], R[x][y]

# 判断有无解 + 收集区间
intervals = []
for j in range(m):
    l, r = dfs(0, j)
    if l != -1:
        intervals.append((l, r))

# 无解情况
covered = [False] * m
for l, r in intervals:
    for k in range(l, r + 1):
        covered[k] = True
uncovered = sum(1 for c in covered if not c)
if uncovered > 0:
    print(0)
    print(uncovered)
    sys.exit()

# 有解 → 贪心
intervals.sort()
ans, i, curr = 0, 0, 0
while curr < m:
    best = -1
    while i < len(intervals) and intervals[i][0] <= curr:
        best = max(best, intervals[i][1])
        i += 1
    if best == -1:
        break
    curr = best + 1
    ans += 1

print(1)
print(ans)
```

## 八、总结

| 步骤 | 做什么 | 技巧 |
|------|--------|------|
| ① | 从第一行搜索，标记可到达的最后一行 | DFS + 记忆化 |
| ② | 判断有无解 | 统计最后一行未标记数 |
| ③ | 证明**每个水库覆盖连续区间** | 反证法（关键） |
| ④ | 算出每个水库的 [L, R] 区间 | 记忆化搜索返回最左最右 |
| ⑤ | **最少区间覆盖**贪心 | 按左端点排序，每次选右端点最远的 |
