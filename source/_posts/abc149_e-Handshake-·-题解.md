# 题解

考虑所有有序对 `(i,j)` 的和 `ai+aj`，共有 `n²` 个值，要求前 `m` 大之和。

直接堆模拟复杂度为 `O(m log m)`，无法通过。

---

## 转化

设一个阈值 `x`，考虑满足：

```text
ai + aj >= x
```

的 pair 数量。

显然：

- `x` 越大，满足条件的 pair 越少
    
- `x` 越小，满足条件的 pair 越多
    

因此满足条件的 pair 数量关于 `x` 具有单调性，可以二分答案。

---

## 二分的意义

最终找到的 `x` 满足：

```text
count(>x) < m
count(>=x) >= m
```

因此：

```text
x 恰好是第 m 大 pair sum
```

于是：

- 所有 `>x` 的 pair 一定全部选
    
- `=x` 的 pair 选择一部分补足到 `m` 个
    

即可得到前 `m` 大之和。

---

## 如何快速统计

先将数组从大到小排序，并统计每个值出现次数 `cnt`。

对于每个 `ai`，双指针找到最大的 `j` 满足：

```text
ai + aj >= x
```

由于数组有序，指针具有单调性，总复杂度 `O(n)`。

再利用前缀和：

- `cs[i]`：前 `i` 个数的出现次数
    
- `pre[i]`：前 `i` 个数的加权和
    

即可快速统计：

- 满足条件的 pair 数量
    
- 所有 pair sum 的总和
    

---

## 特殊处理

由于可能存在大量 pair 满足：

```text
ai + aj == x
```

因此还需要统计等于 `x` 的 pair 数量。

若当前统计得到：

```text
dy = count(>=x)
eq = count(==x)
```

则：

- 若 `dy <= m`  
    说明所有 `>=x` 的都可以选
    
- 若 `dy-eq <= m < dy`  
    说明需要删去多余的 `(dy-m)` 个 `x`
    

答案为：

```text
sum - (dy-m)*x
```

---

## 复杂度

排序：

```text
O(n log n)
```

每次 check：

```text
O(n)
```

总复杂度：

```text
O(n log V)
```

其中 `V` 为值域。
