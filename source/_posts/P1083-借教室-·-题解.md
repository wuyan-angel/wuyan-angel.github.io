题目大意：
给定n天，每天有$r[i]$ 个教室可用，然后给出m个订单，每个订单有 $d,s,t$ 分别为借教室个数，开始时间以及结束时间。
求出从哪个订单开始无法分配教室。
思路1：
利用线段树快速修改区间$s-t$的教室个数，然后利用区间查找查找该区间的最小值，如果最小值小于了0，则从当前开始一定不成立。
思路2：
二分枚举答案，我们假设已知在x点以及不满足条件，那么x后面一定不满足条件，则我们把区间改为$l-x$即可。
代码如下：
```cpp
const int N = 1e6+10;

int r[N],dlt[N],n,m;

struct Node{

int d,s,t;

}e[N];

  

bool check(int x)

{

for(int i=1;i<=n;i++)

dlt[i] = r[i]-r[i-1];

for(int i=0;i<x;i++)

{

int l = e[i].s,r=e[i].t,v=e[i].d;

dlt[l]-=v,dlt[r+1]+=v;

}

for(int i=1;i<=n;i++)

{

dlt[i]=dlt[i]+dlt[i-1];

if(dlt[i]<0) return false;

}

return true;

}

  

void solve()

{

cin>>n>>m;

for(int i=1;i<=n;i++) cin>>r[i];

for(int i=0;i<m;i++) cin>>e[i].d>>e[i].s>>e[i].t;

int l=0,r=m;

while(l<r)

{

int mid = l+r+1 >>1;

if(check(mid)) l=mid;

else r=mid-1;

}

if(l>=m) cout<<0<<endl;

else cout<<-1<<'\n'<<l+1<<endl;

return;

}
```
