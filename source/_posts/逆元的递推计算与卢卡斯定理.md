# 逆元的递推计算与卢卡斯定理

## 1. 逆元的概念
- **定义**：在模 `p` 意义下，`a` 的逆元 `a^{-1}` 是满足 `a * a^{-1} ≡ 1 (mod p)` 的整数。
- **计算方法**（费马小定理）：
  - 当 `p` 是质数时，`a^{-1} ≡ a^{p-2} mod p`。
  - 代码实现：
    ```cpp
    ll qmi(ll a, ll b, ll p) {
        ll res = 1;
        while (b) {
            if (b & 1) res = res * a % p;
            b >>= 1;
            a = a * a % p;
        }
        return res;
    }
    ll inv(ll a, ll p) { return qmi(a, p-2, p); }
    ```

---

## 2. 阶乘逆元的递推计算
### 1 直接计算法
- **公式**：
  $\text{inf}[i] = (i!)^{-1} \equiv (i!)^{p-2} \pmod{p}$
- **缺点**：时间复杂度高（`O(n log p)`），不适合大规模数据。
### 2 递推计算法
- **递推关系**：
  $(i!)^{-1} \equiv \left((i-1)! \cdot i\right)^{-1} \equiv (i-1)!^{-1} \cdot i^{-1} \pmod{p}$
- **公式**：
  $\text{inf}[i] = \text{inf}[i-1] \cdot i^{-1} \pmod{p}$
- **代码实现**：
```cpp
  void init(int n, int p) {
      fa[0] = inf[0] = 1;
      for (int i = 1; i <= n; i++) {
          fa[i] = fa[i-1] * i % p;           // 计算阶乘
          inf[i] = inf[i-1] * inv(i, p) % p;  // 递推阶乘逆元
      }
  }
线性
void init() {
```

## 3.卢卡斯定理：
![](/images/vault/Pasted-image-20250720162017.png)
![](/images/vault/Pasted-image-20250720162245.png)
例题：[卢卡斯定理](https://www.luogu.com.cn/problem/P3807)
最终代码：
```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1e5+10; 
typedef long long ll; 

ll fa[N], inf[N];       // fa存储阶乘数组，inf存储阶乘的逆元数组

// 快速幂函数：计算a^b mod p
ll qmi(ll a, ll b, ll p)
{
    ll res = 1;
    while(b)
    {
        if(b&1) res = res * a % p;  // 如果b是奇数，乘上当前的a
        b >>= 1;                    // b右移一位
        a = a * a % p;              // a平方
    }
    return res;
}

// 初始化函数：预处理阶乘和阶乘逆元
void init(int n, int p)
{
    fa[0] = inf[0] = 1;  // 0的阶乘和逆元都是1
    for(int i = 1; i <= n; i++)
    {
        fa[i] = fa[i-1] * i % p;           // 计算i的阶乘 mod p
        inf[i] = inf[i-1] * qmi(i, p-2, p) % p; // 计算i!的逆元 mod p
    }  
}

// 组合数计算函数：C(a,b) mod p
ll C(ll a, ll b, ll p)
{
    if(b > a) return 0;  // 如果b>a，组合数为0
    // 根据组合数公式：C(a,b) = a! / (b!(a-b)!)
    return fa[a] % p * inf[a-b] % p * inf[b] % p;
}

// 卢卡斯定理递归实现
ll lucas(ll a, ll b, ll p)
{
    if(a < p && b < p) return C(a, b, p);  // 当a,b都小于p时直接计算
    // 卢卡斯定理：C(a,b) ≡ C(a%p,b%p) * C(a/p,b/p) (mod p)
    return C(a % p, b % p, p) * lucas(a / p, b / p, p) % p;
}

// 解决函数：处理每个测试用例
void solve()
{
    int n, m, p;
    cin >> n >> m >> p;
    n = n + m;  // 计算n+m
    init(n, p); // 预处理阶乘和逆元
    ll res = lucas(n, m, p);  // 使用卢卡斯定理计算结果
    cout << res << endl;       // 输出结果
}

int main()
{
    int _;  // 测试用例数量
    cin >> _;
    while(_--) solve();  // 处理每个测试用例
    return 0;
}
```
总结：利用卢卡斯定理结合快速幂和逆元的知识可以解决当![](/images/vault/Pasted-image-20250720163203.png)n和m非常大时的问题
特别是当m大于p时，因为此时m的阶层一定包含p，所以求逆元一定为0，即使实际组合数并不为 0
![](/images/vault/Pasted-image-20250821195139.png)
### 为什么实际答案不为 0？

卢卡斯定理告诉我们，对于组合数 `C(n, m) % p`，可以将 `n` 和 `m` 表示为 `p` 进制的数，然后递归地计算每个 `p` 进制位上的组合数的乘积。直接计算阶乘和逆元的方法仅在 `n < p` 时有效。当 `n >= p` 时，必须使用卢卡斯定理来分解问题。

## 2.树状数组复习
树状数组可以解决大部分区间上面的修改以及查询的问题，例如
**1.单点修改，单点查询，
2.区间修改，单点查询，
3.区间查询，区间修改**，
换言之，线段树能解决的问题，树状数组大部分也可以，但是并不一定都能解决，因为线段树的扩展性比树状数组要强
### 问题引入
![](/images/vault/Pasted-image-20250720211727.png)
显然，我们一开始会想到暴力的朴素做法，单点修改操作时间复杂度O(1)，区间求和，暴力遍历区间每一个数再相加时间复杂度O(n)，如果区间求和查询的次数为n次，那么中的时间复杂度为$O(n^2)$,对于大数据的题来说肯定会T，此时如果用树状数组的话复杂度可以讲到$O(nlogn).$
![](/images/vault/Pasted-image-20250720211645.png)
上面时树状数组的结构图，$t[x]$保存以x为根的子数中叶子节点值的和,原数组为$a[]$  
那么原数组前4项的和$t[4]=t[2]+t[3]+a[4]=t[1]+a[2]+t[3]+a[4]=a[1]+a[2]+a[3]+a[4]$,看似没有什么特点，别着急往下看
![](/images/vault/Pasted-image-20250720230736.png)
我们通过观察节点的二进制数，进一步发现，树状数组中节点x的父节点为$**x+lowbit(x)$,例如t[2]的父节点为$t[4]=t[2+lowbit(2)]$

## 1.单点修改，区间查询
```cpp
int add_dandian(int x,int k)
{
	for(int i=x;i<=n;i+=lowbit(i))
	t[i]+=k;
}

```
所以我们在**单点修改**的同时，更新父节点就变得尤为简单，，例如我们对$a[1]+k$，那么祖先节点$t[1],t[2],t[4],t[8]$都需要+k更新(因为t[]表示前缀和)，此时我们就可以用$lowbit$操作实现
那么单点修改实现了，如何实现区间查询呢？  
例如：我们需要查询前7项的区间和$sum[7]$
![](/images/vault/Pasted-image-20250720231010.png)
通过图中不难看出，$sum[7]=t[7]+t[6]+t[4]$ ,我们进一步发现,$6=7-lowbit(7),4=6-lowbit(6)$，所以我们可以通过不断的$-lowbit$操作来实现求和
```cpp
int ask(x){
	int sum = 0;
	for(int i=x;i;i-=lowbit(i)){
		sum+=t[i];
	}
	return sum;
}

```
这只能求区间$[ 1 , x ]$ 的区间和，那么如何求 $[ L , R ]$的区间和呢？ $[1,x]$的区间和，那么如何求$[L,R]$的区间和呢？$[1,x]$的区间和，那么如何求$[L,R]$的区间和呢？，这时候利用前缀和相减的性质就可以了，$[ L , R ] = [ 1 , R ] − [ 1 , L − 1 ] [L,R]=[1,R]-[1,L-1][L,R]=[1,R]−[1,L−1]$
```cpp
int search(int L,int R)
{
	int ans = 0;
	for(int i=L-1;i;i-=lowbit(i))
	ans-=c[i];
	for(int i=R;i;i-=lowbit(i))
	ans+=c[i];
	return 0;
}

```
## 2.区间修改，单点查询
对于这一类操作，我们需要构造出原数组的差分数组c，然后用树状数组维护c数组即可

对于区间修改的话，我们只需要对差分数组进行操作即可，例如对区间$[L,R]+k$,那么我们只需要更新差分数组$add(L,k),add(R+1,-k)$，这是差分数组的性质.
```cpp
int update(int pos,int k)//pos表示修改点的位置,K表示修改的值也即+K操作
{
	for(int i=pos;i<=n;i+=lowbit(i))
	c[i]+=k;
	return 0;
}
update(L,k);
update(R+1,-k);

```
对于单点查询操作，求出c数组的前缀和即可，因为$a[x]=$差分数组$c[1]+c[2]+…+c[x]$的前缀和，这是差分数组的性质之一.
```cpp
ll ask(int pos)//返回区间pos到1的总和
{
	ll ans=0;
	for(int i=pos;i;i-=lowbit(i)) ans+=c[i];
	return ans;
} 

```
