# 二分算法
二分查找，也称为折半查找（Binary Search），是一种在有序数组中查找特定元素的搜索算法。二分查找的时间复杂度为$O(logn)$，即查找效率较高。
二分的使用题型：
1.答案是具有单调性的，我们可以根据某个答案判断是否满足条件若不满足则尝试更小值若满足则尝试更大值
2.二段性（整个区间一分为二，一段区间满足，一段区间不满足）。
3.二分可以简单分为`二分查找`与`二分答案`，由于二分查找较为简单，所以只对二分答案作出重点理解。
TIPS:利用 left + (right - left) / 2避免了数据范围溢出的风险。
模板如下：
```cpp
bool check(int x) {/* ... */} // 检查x是否满足某种性质

// 区间[l, r]被划分成[l, mid]和[mid + 1, r]时使用：
int bsearch_1(int l, int r)
{
    while (l < r)
    {
        int mid = l + r >> 1;
        if (check(mid)) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}
// 区间[l, r]被划分成[l, mid - 1]和[mid, r]时使用：
int bsearch_2(int l, int r)
{
    while (l < r)
    {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
//写check ，满足与不满足分别更新哪个区间；
```
例题：
[Problem - 5936](https://acm.hdu.edu.cn/showproblem.php?pid=5936)
题目大概描述
f(x,k)函数代表该数(k)各个位的k次方
x = f(y,k) - y
已知x，k 求y的所有结果
读题时发现了x = $1e9$，t为100
我们容易发现y是小于等于$1e10$的，因为$999999999>=81*9$,后续无论怎么取都是不成立的.
但是我们直接枚举1-$1e10$显然是会爆炸的，由此我们可以想到利用折半枚举，我们将1-$1e5$这一半全部预处理出来
为什么可以使用折半枚举，这里要根据题目推个公式：
$x=f(y,k)-y = f(y1,k) - y1 +f(y2*1e5,k)-y2*1e5$
$x - (f(y1,k)-y1) = f(y2*1e5,k)-y2*1e5$
相当于我们需要把$f(y1,k)$的所有情况预处理了
$g[i][j]$代表f(i,j) 我们将g预处理之后的值
然后我们可以将左式用一个一位数组存储
然后我们遍历右式的所有情况(由于前面一位存储左式的情况与顺序无关，于是可以排序，排序后可以利用二分查找找到所有满足条件点的个数即：
```cpp
upper_bound(a,a+N,tmp)-lower_bound(a,a+N,tmp)
```
特别的当x=0时答案因是0，这里特别判断即可，代码如下:
```cpp

#include<bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N = 1e5+10,_1e5=1e5;
ll f[11][11],g[N][11];
void pt(int a,ll b)
{
    cout<<"Case #"<<a<<": "<<b<<endl;
}
void Init()
{
    for(int i=0;i<=9;i++)
    {
        f[i][0]=1;
        for(int j=1;j<=9;j++)
        {
            f[i][j] = f[i][j-1]*i;
        }
    }
    memset(g,0,sizeof g);
    for(int i=1;i<=9;i++)
    {
         for(int j=0;j<N;j++)
         {
             int tmp = j;
             while(tmp)
             {
                 int x = tmp%10;
                 g[j][i]+=f[x][i];
                 tmp/=10;
                 //cout<<j<<endl;
             }
         }   
    }
}
ll a[N];
ll solve()
{
    ll x,k;
    cin>>x>>k;
    ll res = 0;
    for(ll i=0;i<N;i++) a[i] = g[i][k]-(ll)i*_1e5;
    sort(a,a+N);
    for(ll i=0;i<N;i++)
    {
        ll tmp = g[i][k]-i;
        tmp= x -tmp;
        res += upper_bound(a,a+N,tmp)-lower_bound(a,a+N,tmp);
    }
    return res-(x==0);
   // cout<<res<<endl;
}

int main()
{
    Init();
    int _;
    cin>>_;
    for(int i=1;i<=_;i++)
    {
        pt(i,solve());
    }
    return 0;
}
```
