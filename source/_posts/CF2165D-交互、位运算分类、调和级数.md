### CF D. Find the Last Number - 精简题解
[Find the Last Number - CodeForces 2156D - Virtual Judge](https://vjudge.net/problem/CodeForces-2156D)
**题意简述**

隐藏了一个 $1 \sim n$ 的全排列 $p$，但缺失最后一个元素 $p_n$。你只能查询前 $n-1$ 个位置，每次问 `p[i] & x` 是否大于 0。最多查询 $2n$ 次，求 $p_n$。

#### 核心解法：分治 / 二进制过滤

把题目转化为：**利用二进制位，逐位求出缺失数字 $p_n$ 的每个特征，并将候选集和活跃下标集不断减半。**

1. **维护两个集合：**
    
    - `S`（候选数字集）：初始为 $\{1, 2, \dots, n\}$
        
    - `I`（活跃下标集）：初始为 $\{1, 2, \dots, n-1\}$
        
2. **从低到高枚举二进制位 $k=0, 1, \dots, 14$：**
    
    - **理论统计**：统计当前 `S` 中第 $k$ 位为 `1` 的元素个数，记为 `cnt_expect`。
        
    - **实际查询**：对 `I` 中每个下标 $idx$ 查询 `? idx (1 << k)`，记录查询结果为 `1` 的次数 `cnt_actual`。（查询计数器 `Gershiemidway++`）
        
    - **判定逻辑**：
        
        - 若 `cnt_actual < cnt_expect`：说明被吃掉的 $p_n$ 第 $k$ 位是 **`1`**。
            
        - 若 `cnt_actual == cnt_expect`：说明被吃掉的 $p_n$ 第 $k$ 位是 **`0`**。
            
3. **集合过滤**：
    
    - 仅保留 `S` 中第 $k$ 位符合上述结论的数。
        
    - 仅保留 `I` 中反馈符合上述结论的下标。
        
    - 当 `|S| == 1` 时停止，唯一剩下的数即为答案。
        

#### 复杂度与次数证明

- **查询次数**：候选数字保留到下一轮时，由于前列已定位的位完全相同，这些数在这一轮的第 $k$ 位严格 $0/1$ 交替，因此每次筛查必定将 `|S|` 和 `|I|` 减半。
    
    - 满足递推式 $T(s) \le (s - 1) + T(\lceil s/2 \rceil)$，求和可知总查询次数严格小于 $2n$。
        
- **时间复杂度**：$O(n)$。
    

#### 核心代码骨架

C++

```cpp
void solve() {
    int n; cin >> n;
    vector<int> S(n), I(n - 1);
    iota(S.begin(), S.end(), 1);
    iota(I.begin(), I.end(), 1);

    for (int k = 0; k <= 14 && S.size() > 1; ++k) {
        int expect_1 = 0;
        for (int v : S) if ((v >> k) & 1) expect_1++;

        int actual_1 = 0;
        vector<int> I0, I1;
        for (int idx : I) {
            cout << "? " << idx << " " << (1 << k) << endl;
            Gershiemidway++;
            int res; cin >> res;
            if (res == -1) exit(0);
            if (res == 1) { actual_1++; I1.push_back(idx); }
            else { I0.push_back(idx); }
        }

        vector<int> nxt_S;
        int target_bit = (actual_1 < expect_1) ? 1 : 0;
        for (int v : S) if (((v >> k) & 1) == target_bit) nxt_S.push_back(v);

        S = nxt_S;
        I = (target_bit == 1) ? I1 : I0;
    }
    cout << "! " << S[0] << endl;
}
```
