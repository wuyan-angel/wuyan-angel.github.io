# 题解：A Lot of Paintings (VJudge - REG预备役特训题2)
[A Lot of Paintings - Problem - QOJ.ac](https://qoj.ac/problem/14706)
## 题目大意

给定 $n$ 个参与者的提交占比百分比数组 $a = [a_1, a_2, \dots, a_n]$（已知 $a_i \in [0, 100]$ 的整数，是由真实比例四舍五入保留两位小数后乘以 $100\%$ 得到的）。
  

你需要还原出一个非负整数数组 $b = [b_1, b_2, \dots, b_n]$（满足 $\sum b_i > 0$），使得每个 $b_i$ 在总和中占的比例四舍五入后**刚好等于** $a_i$。如果不存在这样的数组，输出 `No`。

## 核心破题点：四舍五入的“容差边界”

没有四舍五入时，所有占比之和必然严格等于 $100\%$。但因为有了四舍五入，每一个 $a_i$ 相比于真实占比 $p_i$ 都有 **$\pm 0.5\%$ 的误差容限**：

$$a_i - 0.5 \le p_i < a_i + 0.5$$

利用这个上下限对所有元素求和，就能导出**存在解的充要条件**，接着利用这个条件直接**线性构造**出合法的 $b$ 数组。

  

## 一、 判定条件推导（充要条件）

令 $T = \sum_{i=1}^n a_i$ 为输入数组的总和，$k$ 为非零元素的个数（$a_i > 0$ 的数量）。

  

真实的占比总和必然满足 $\sum p_i = 100\%$。

  

### 1. 压低上限（削峰边界）：$2T - k \le 200$

- 对于 $a_i > 0$ 的元素，真实值允许扣减的最大极限是 $a_i - 0.5$；
    
      
    
- 对于 $a_i = 0$ 的元素，因为 $b_i \ge 0$，真实值下限只能是 $0$（不能比 $0$ 更小）；
    
      
    
- 因此，所有元素的真实占比下限之和不能超过 $100$：
    
      
    
    $$T - 0.5k \le 100 \implies 2T - k \le 200$$
    

### 2. 抬高下限（填谷边界）：$2T + n > 200$

- 对于任意 $a_i$（包括 $0$），真实值上界严格小于 $a_i + 0.5$；
    
      
    
- 因此，所有元素的真实占比上界之和必须能超过 $100$：
    $$T + 0.5n > 100 \implies 2T + n > 200$$
    

只要不满足上述任意一个式子，直接判定为 `No`。

  

## 二、 构造策略（O(n) 复杂度）

在满足判定条件前提下，按照 $T$ 与 $100$ 的关系分类讨论：

  

### Case 1: $T = 100$

直接令 $b_i = a_i$ 即可，总和恰好为 $100$。

  

### Case 2: $T > 100$（总和溢出，需要“削峰”）

- **调整量**：总和超出了 $T - 100$。
    
      
    
- **策略**：从 $k$ 个非零元素中挑选出 $2(T - 100)$ 个，将它们的占比各减少 $0.5$。
    
      
    - 总共减少：$2(T - 100) \times 0.5 = T - 100$，正好把总和压回 $100$。
        
          
        
    - **非零元素够用吗？** 判定条件 $2T - k \le 200 \implies 2(T - 100) \le k$，证明非零个数 $k$ 一定足够。
        
          
        
- **整数化**：整体乘以 $10$，消去 $0.5$：
    
      
    - 被削减的元素：$b_i = 10a_i - 5$
        
          
        
    - 未削减的元素：$b_i = 10a_i$
        
          
        

### Case 3: $T < 100$（总和不足，需要“填谷”）

- **调整量**：总和缺少 $100 - T$。
    
      
    
- **策略**：不能只给部分元素加 $0.5$（因为 $a_i + 0.5$ 四舍五入后会进位变成 $a_i + 1$），正确的做法是将缺口 **雨露均沾地分给所有 $n$ 个元素**。
    
      
    - 每个元素增加量：$\Delta = \frac{100 - T}{n}$。
        
          
        
    - **为什么不会触发进位？** 判定条件 $2T + n > 200 \implies 100 - T < \frac{n}{2} \implies \frac{100 - T}{n} < 0.5$。加上的值**严格小于 $0.5$**，四舍五入后依然保留为 $a_i$！
        
          
        
- **整数化**：整体乘以 $n$，消去分母：
    
      
    - 每个元素：$b_i = n \cdot a_i + (100 - T)$
        
          
        

## 三、 避坑指南（易错点总结）

1. **计数器扣减**：在 $T > 100$ 挑选 $2(T - 100)$ 个元素修改时，修改完一个必须执行 `tmp--`，不能漏掉。
    
      
    
2. **$T < 100$ 的数学逻辑**：绝对不能给部分元素直接 $+0.5$，必须用统一加分式 $\frac{100-T}{n}$ 再乘 $n$ 消分母的策略。
    

## 四、 AC 代码实现

C++

```
#include <bits/stdc++.h>
#define rep(i, n) for (int i = 0; i < n; i++)
#define IOS ios::sync_with_stdio(false), cin.tie(nullptr);
using namespace std;
typedef long long ll;

void solve() {
    ll n;
    cin >> n;
    ll sum = 0, k = 0;
    vector<ll> a(n);
    
    rep(i, n) {
        cin >> a[i];
        sum += a[i];
        if (a[i] > 0) k++;
    }

    // 1. 充要条件判定
    if (2 * sum - k > 200 || 2 * sum + n <= 200) {
        cout << "No\n";
        return;
    }

    cout << "Yes\n";

    // 2. O(n) 构造
    vector<ll> b(n);
    if (sum == 100) {
        rep(i, n) b[i] = a[i];
    } 
    else if (sum > 100) {
        ll tmp = (sum - 100) * 2; // 需要削减 0.5 的元素个数
        rep(i, n) {
            if (a[i] > 0 && tmp > 0) {
                b[i] = 10 * a[i] - 5;
                tmp--; // 必须自减！
            } else {
                b[i] = 10 * a[i];
            }
        }
    } 
    else { // sum < 100
        ll diff = 100 - sum;
        rep(i, n) {
            b[i] = a[i] * n + diff; // 整体乘 n 消除分母
        }
    }

    // 3. 输出答案
    rep(i, n) {
        cout << b[i] << (i == n - 1 ? "" : " ");
    }
    cout << "\n";
}

int main() {
    IOS;
    int _ = 1;
    if (cin >> _) {
        while (_--) solve();
    }
    return 0;
}
```
