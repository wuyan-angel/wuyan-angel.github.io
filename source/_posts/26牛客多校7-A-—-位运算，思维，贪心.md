## 题目大意

给定数组 `a[1..n]`。你可以选择一个整数 `x`（一个掩码），然后对**每个** `a[i]`，把它异或上任意一个 `t`，其中 `t` 的每一位都必须是 `x` 中有的位（即 `t ⊆ x`，`t & ~x == 0`）。要求操作后数组**非递减**。求最小的 `x`。

- 例如 `x = 5 (101)`：每个数只能翻第 0 位和第 2 位。
- 掩码越小越好，`x = 0` 表示原数组已经非递减。

## 关键性质

1. **可达值集合**：对固定掩码 `M`，`a[i]` 能变成的所有值是 `{ a[i]^t : t ⊆ M }`。位不在 `M` 里的叫"不可动位"，必须保持 `a[i]` 原样。
2. **可行性对"位包含"单调**：`M` 可行 ⟹ 任何 `M' ⊇ M`（多买位）也可行。多买位只会增加自由度，不会变难。
3. **对"数值大小"不单调**：掩码 `2` 可行但掩码 `2^29` 不可行（只买最高位时，`3,2,1` 的相对顺序改不了）。所以**不能数值二分**。

## 思路

### 第一层：`check(M)` —— 给定掩码能否排成非递减

从左到右贪心，维护 `pre`（前一个改造后的值）。对每个位置，取：

> 能达到的、且 **≥ pre** 的**最小**值。

取最小是对的：当前位置越小，留给后面的空间越大。

**如何求"≥ pre 的最小可达值"**：先令 `now = a[i] | M`（把所有可动位置 1，得到最大可达值），然后从**高位到低位**枚举可动位，只要"翻掉这位（1→0）后仍 ≥ pre"就翻掉。由于所有可动位初始都是 1，每次翻位只变小，最终单调逼近 pre，得到的就是最小可达值。

**为什么贪心对（反证）**：设结果为 `v`，若存在 `v'` 可达且 `pre ≤ v' < v`，取 `v'` 与 `v` 最高的不同位 `h`（v' 为 0，v 为 1）。贪心处理到第 `h` 位时更高位已定、更低位还是全 1，故"当时翻掉 h"得到的值 ≥ v'，而贪心没翻说明它 < pre，于是 `v' < pre`，矛盾。

任一位置取不到（`now < pre`）则 `check` 返回 `false`。

### 第二层：外层逐位贪心（从全买出发，能省就省）

Cpp

ll ans = (1ll<<31) - 1;                    // 全买（bits 0..30），必然可行

for(ll i=30; i>=0; i--)

    if(check(ans ^ (1ll<<i))) ans ^= (1ll<<i);   // 去掉第 i 位仍可行 → 去掉

处理第 `i` 位时，更高位已定为最终值，更低位暂时全 1，所以 `ans^(1<<i)` 是"第 i 位=0 的最乐观掩码"：

- 它可行 ⟹ 存在"第 i 位=0"的可行掩码 ⟹ 最优解必然省掉第 i 位 → 去掉；
- 它不可行 ⟹ 任何"第 i 位=0"的掩码都不可行 ⟹ 第 i 位必须买 → 保留。

（等价于从 0 出发"试 0、不行才买"，只是方向相反。）由单调性，最终 `ans` 就是最小可行掩码。

## 复杂度

外层 31 次 check，每次 O(30·n)，总 **O(30²·n)**，空间 O(n)。`n ≤ 2e5` 轻松通过。

## 参考代码

Cpp

#include<bits/stdc++.h>

using namespace std;

typedef long long ll;

const int N = 2e5+10;

ll a[N], n;

bool check(ll x) {

    ll pre = 0;

    for(int i = 1; i <= n; i++) {

        ll now = a[i] | x;                      // 最大可达值

        for(ll j = 30; j >= 0; j--) {

            if((x & (1ll<<j)) == 0) continue;   // 没买的位不能动

            if((now ^ (1ll<<j)) >= pre) now ^= (1ll<<j);

        }

        if(now < pre) return false;

        pre = now;

    }

    return true;

}

void solve() {

    cin >> n;

    for(int i = 1; i <= n; i++) cin >> a[i];

    ll ans = (1ll<<31) - 1;

    for(ll i = 30; i >= 0; i--)

        if(check(ans ^ (1ll<<i))) ans ^= (1ll<<i);

    cout << ans << '\n';

}

int main() {

    ios::sync_with_stdio(false);

    cin.tie(nullptr);

    int T; cin >> T;

    while(T--) solve();

}
