首先先讨论用中序遍历+前序/后续求没有的，此时情况是固定的。
前置知识：
三种遍历方式的区别是：根何时遍历。
前序遍历是先遍历根，再分别遍历左右子树，左右子树中也是先遍历子树的根，简称根左右；
中序遍历是先遍历左子树，再遍历根，最后遍历右子树，左右子树中也是如此，简称左根右；
后续遍历是先遍历左子树，再遍历右子树，最后遍历根，左右子树中也是如此，简称左右根。
## 1.已知中序前序求后序.
![](/images/vault/Pasted-image-20250805131050.png)
由上可以发现前序的最左边一定是根，于是找到了根，然后在中序找到根，则可以将左右区分开，1左边的即是左子树，右边的是右子树，然后由于遍历方法我们可以发现，设根左边长度为x，则前序遍历中的左子树的长度一定也为x，右子树长度即可以计算出，我们仅讲解递归一层后的效果，此时上面的情况变为：![](/images/vault/Pasted-image-20250805131400.png)
此时递归进入左子树，然后又可以由前序遍历可知2一定是左子树的根，然后我们可以找到中序遍历左子树与其相同的节点，又以2为中心将左右以上面同样的方式递归进入，直到无法拆分，代码如下：
```cpp
const int N = 2e5+10;

int a[N],b[N];

int n;

unordered_map<int, int> pos;

inline void hy(int ql,int qr,int zl,int zr)

{

if(ql>qr) return ;

int root = a[ql];

int t = pos[root];

int len = t-zl;

hy(ql+1,len+ql,zl,t-1);

hy(ql+len+1,qr,t+1,zr);

cout<<root<<' ';

}

  

void solve()

{

cin>>n;

for(int i=1;i<=n;i++) cin>>a[i];

for(int i=1;i<=n;i++) cin>>b[i];

for (int i = 1; i <= n; i++) pos[b[i]] = i;

hy(1,n,1,n);

}
```
## 2.已知中序后序求前序.
这里就和上面几乎一模一样，不同的是后序遍历的根在最左边，即我们每次取最左边即可，不过多赘述。
## 3.已知前序后序求中序
![](/images/vault/Pasted-image-20250805132343.png)
上图中，在前序遍历和后序遍历中将根节点确定下来之后，结合前序遍历和后序遍历的特点，就可以将根节点的左右子树都确定出来。因为前序遍历属于深度优先遍历，也就是“一挖到底”，所以从上图中可以知道左子树的根节点是2，右子树的根节点是3，那么在中前序遍历和后序遍历中可以进一步找到左右子树的左右子树，那么这个问题就可以进一步缩小，且符合递归的规律，所以完全可以使用递归来解决这个问题。 
从上图中，我们可以分析成文字如下所示：
![](/images/vault/Pasted-image-20250805133456.png)
在找根节点的时候，都是以这两个整体序列为基础的，所以前序遍历序列的起止位置是$[ps, pe]，即为[0, pre.length - 1]，$$后序遍历序列的起止位置是$$[pos, poe]，即为[0, post.length - 1]；$
那么在处理左子树的时候，需要在这两个序列中将左子树的部分截取出来，所以在前序遍历序列中的起止位置是$[ps + 1, ps + leftChildTreeNodeNum]$，$在后序遍历序列中的起止位置为：[pos, leftRootIndex]；$
那么在处理右子树的时候，也同样需要在这两个序列中将右子树的部分截取出来，所以在前序遍历序列中的起止位置是$[ps + leftChildTreeNodeNum + 1, pe],在后序遍历$
$序列中的起止位置为：[leftRootIndex + 1, poe - 1];$
```cpp
void zx(int ql,int qr,int hl,int hr)

{

if(ql>qr) return;

if(ql==qr)

{

ans.push_back(a[ql]);

return;

}

int root = a[ql],t = mp[a[ql+1]];

int len = t-hl;

zx(ql+1,ql+len+1,hl,t-1);//左节点跳过根和其余部分又节点一样

ans.push_back(root);

zx(ql+len+2,qr,t+1,hr-1);

}
```
